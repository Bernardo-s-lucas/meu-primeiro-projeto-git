## Reflexão Final

**1. Qual a importância do Git para desenvolvimento de software?**  
O Git funciona como um histórico completo do projeto ele garante que qualquer mudança feita no código fique salva com segurança, permitindo voltar caso algo de errado e garantindo que o progresso não seja perdido.

**2. Como o uso de branches pode ajudar no trabalho em equipe?**  
As branches permitem que cada pessoa trabalhe em uma parte do projeto sem mexer no código principal (`main`). Isso evita que uma alteração incompleta quebre o sistema para os outros e facilita bastante trabalho em equipe.

**3. Por que é importante escrever mensagens de commit claras?**  
ajuda a entender exatamente o que foi alterado em cada etapa sem precisar ler linha por linha do código.

**4. Quando você usaria o arquivo .gitignore?**  
Sempre que o projeto tiver arquivos sensiveis que não precisam ir para o repositório público, como senhas, APIS, arquivos temporários ou pastas de configuração da IDE.

**5. Como o histórico de commits do seu repositório demonstra seu aprendizado?**  
O histórico mostra passo a passo da evolução do projeto, desde os comandos mais básicos até o trabalho com branches e a resolução de conflitos de merge.
